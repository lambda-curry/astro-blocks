# Astro Blocks gallery

- **Visitor and first action:** Astro developers and AI-assisted site owners deciding whether a block fits their site. First action: open a block and see it live in their kind of theme.
- **Thesis:** a quiet, precise frame that lets eighteen very different blocks be the color in the room. The gallery chrome is built from the registry's own blocks.
- **Signature move:** every card and preview is the real block running live (scaled iframes at 1280px and 390px), restyled in place by four token themes.
- **Type:** one system grotesk for display and body; display weight 700 at -0.03em. Code and item names in the platform monospace stack.
- **Palette roles:** paper white `#f7f7f3` background, `#ebebe4` surface, near-black `#151514` text, `#595954` muted, ultramarine `#3434e0` accent with white on accent. 2px near-black rules mark categories.
- **Homepage order:** typographic hero with install facts; install for any Astro project and for Site Boulder; the catalog by category with theme switch and search; "Optional by design" principles.
- **Imagery:** only the original SVG artworks in `public/gallery/` and the blocks themselves. No third-party images or screenshots.
- **Invariants:** one h1 per page, 44px targets, visible focus, no horizontal overflow at 390px, no client JavaScript required to read or navigate (search, copy and in-place theme switching are enhancements).
