# Astro Blocks

Open-source, Astro-first, shadcn-compatible source registry of polished website blocks —
headers, heroes, walkthroughs, features, and footers. Native `.astro` components, scoped CSS,
semantic tokens, typed props and slots, minimal JS, minimal dependencies.

Beautiful by default. Freely customizable. Bring your own site.

> Early scaffold — registry format, component catalog, and CLI distribution are being defined.
> See the repository roadmap for the current status.

## Status

Work in progress. Distribution will target shadcn-compatible registry JSON (validated against
the shadcn schema/CLI for native .astro files) served from this repository.
